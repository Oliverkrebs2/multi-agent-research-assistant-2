# Multi-Agent Research Assistant

Multi-agent AI research platform that uses specialized LLM agents to plan, research, fact-check, summarize, and generate citations from documents and web sources.

## What It Does

- Breaks research tasks into smaller steps
- Uses specialized agents for planning, research, summarization, and fact-checking
- Produces structured research reports
- Tracks sources and citations
- Supports document-based research workflows
- Designed for extensible AI agent orchestration

## Tech Stack

- Python
- FastAPI
- LangGraph-style agent architecture
- PostgreSQL
- Vector search
- OpenAI API
- Docker
- GitHub Actions

## Agent Pipeline

User Query → Planner Agent → Research Agent → Fact Checker Agent → Summarizer Agent → Final Report

## Use Cases

- Market research
- Technical research
- Document analysis
- Competitive intelligence
- Academic-style summarization
- Internal knowledge base search
